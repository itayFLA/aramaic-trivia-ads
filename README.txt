מחולל פרסומות - ארמית טריוויה
=================================

התקנה (פעם אחת)
1. Python 3  -  https://www.python.org/downloads  (לסמן Add Python to PATH)
2. בטרמינל:   pip install pillow python-bidi
3. FFmpeg:     winget install ffmpeg   (ואז לפתוח את הטרמינל מחדש)

שימוש
1. פותחים את questions.txt וכותבים שלוש שאלות לכל פרסומת (הפורמט מוסבר בראש הקובץ).
2. מריצים:  python make_ads.py     (או לחיצה כפולה על run.bat)
3. הסרטונים נשמרים בתיקיית output.

אפשרויות
  python make_ads.py --only 2     רק פרסומת מספר 2
  python make_ads.py --preview    תמונות בדיקה בלבד, מהיר, בלי וידאו
  python make_ads.py קובץ.txt      קובץ שאלות אחר

מה קבוע ומה משתנה
- משתנה: 3 השאלות, התשובות והתשובה הנכונה.
- קבוע: הרקע, העיצוב, הסיום ("כמה קלעתם?" + הלוגו) והסאונד.
- התזמון זהה לפרסומת המקורית כדי שהסאונד יישאר מסונכרן. אפשר לשנות בראש make_ads.py,
  אבל אז הסאונד לא יתאים (אפשר להחליף את assets/sound.m4a).
- טקסט הסיום: משתנה END_TEXT בראש make_ads.py.
- להחלפת רקע/לוגו/סאונד מחליפים את הקבצים בתיקיית assets (שומרים על אותם שמות).

טיפים
- שאלה ארוכה מתכווצת אוטומטית עד 3 שורות. עדיף עד כ-70 תווים.
- אפשר להשתמש בניקוד ובגרשיים בתוך השאלה.

======================== הקראה (גרסה 2) ========================
python make_ads.py questions.txt --voice auto
  הקול מקריא את השאלה, אחריה תקתוק, ואז את התשובה הנכונה. אורך הסרטון נגזר מאורך ההקראה.
  הסיום הקבוע נלקח מהסאונד המקורי.

ספקי קול (--voice):
  gemini  Google Gemini TTS  (דורש GEMINI_API_KEY מ-aistudio.google.com/apikey, מסלול חינמי)
  edge    edge-tts           (בלי מפתח, שירות לא רשמי)
  auto    gemini אם יש מפתח, ואם נכשל עובר ל-edge
  none    הסאונד המקורי הקבוע (ברירת מחדל)
התקנה נוספת:  pip install edge-tts
משתני סביבה אופציונליים: GEMINI_TTS_MODEL, GEMINI_VOICE (ברירת מחדל Orus), GEMINI_STYLE, EDGE_VOICE

הגייה: בשורה אפשר לכתוב "מה שמוצג || מה שמוקרא" כדי להקריא עם ניקוד בלי לנקד את המסך, למשל:
  מה פירוש המילה "מתניתין"? || מה פירוש המילה "מַתְנִיתִין"?

בנק שאלות: קובץ אחד עם שאלות רצופות. כל 3 שאלות = פרסומת.
  --skip N   לדלג על N פרסומות שכבר הופקו
  --count M  להפיק רק M פרסומות
